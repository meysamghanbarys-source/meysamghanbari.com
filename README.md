# meysamghanbari.com — Website v2

Official bilingual research website for Meysam Ghanbari.

## Positioning

The site is written in a formal third-person voice as a research profile with a restrained space-technology visual system.

Primary identity:

**Researcher in Optical, Satellite & Advanced Communication Systems**

## Main sections

- Home
- Research
- Projects
- Publications
- Videos & Talks
- Insights
- Upcoming
- Media
- About
- Contact
- Persian equivalents under `/fa/`

## Content sources for this version

The research profile, technical expertise, projects and publication records were organized from the supplied CV. Website publication summaries are concise editorial descriptions and are deliberately conservative where the final paper text/abstract was not supplied.

## Stack

- Astro
- Cloudflare Pages
- English primary + Persian
- Static output
- Sitemap
- Person structured data
- structured media assets

## Design system

The English and Persian homepages share one editorial layout. Shared page templates use a dark scientific palette, section-specific photography, concise headings, responsive grids and descriptive imagery. Research, publications, projects and Insights remain distinct but visually connected.

## Cloudflare settings

- Output directory: `dist`
- Production branch: `main`
