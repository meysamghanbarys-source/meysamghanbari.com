# Image library

Recommended structure:

- `meysam-ghanbari-portrait.webp`
- `projects/<project-slug>/hero.webp`
- `publications/<paper-slug>/cover.webp`
- `media/<year>/<descriptive-image-name>.webp`

For Google Images and accessibility:

- Use original, high-resolution images.
- Use descriptive filenames.
- Write accurate alt text.
- Do not keyword-stuff filenames or alt text.
- Keep professional portraits and event photos visually distinct.
- Export WebP/AVIF for web use while preserving original masters elsewhere.
